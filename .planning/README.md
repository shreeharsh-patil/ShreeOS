# Project Planning

GSD Core onboarding and planning artifacts for ShreeOS.

- `PROJECT.md` — project charter and scope
- `REQUIREMENTS.md` — functional and non-functional requirements
- `ROADMAP.md` — milestone plan and status
- `STATE.md` — current implementation state
- `config.json` — GSD Core configuration
- `phases/` — per-phase implementation plans
- `codebase/` — codebase map
- `onboarding/` — environment setup records
