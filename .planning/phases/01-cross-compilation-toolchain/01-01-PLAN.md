<objective>
Build the complete cross-compilation toolchain for ShreeOS: binutils, GCC (2-pass), glibc, and Linux kernel headers, producing a self-contained cross-compiler at $LUMEN_TOOLS that targets x86_64-shreeos-linux-gnu.

Purpose: Every component in ShreeOS is compiled with this toolchain. It must be built first and must never leak host system paths.
Output: Self-contained cross-compiler toolchain under $LUMEN_TOOLS/bin/ that produces working x86_64 binaries.
</objective>

    - VER_BINUTILS="2.43.1"
    - VER_GCC="14.2.0"
    - VER_GLIBC="2.40"
    - VER_LINUX_KERNEL="6.10"

    Create toolchain/scripts/sources.list with format:
    ```
    # binutils
    BINUTILS_URL=https://sourceware.org/pub/binutils/releases/binutils-2.43.1.tar.xz

    # GCC
    GCC_URL=https://gcc.gnu.org/pub/gcc/releases/gcc-14.2.0/gcc-14.2.0.tar.xz
    GCC_SHA256=<compute>

    # glibc
    GLIBC_URL=https://ftp.gnu.org/gnu/glibc/glibc-2.40.tar.xz

    KERNEL_URL=https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.10.tar.xz
    KERNEL_SHA256=<compute>
    ```
